Bundled Google Fonts
====================

Every font file in this directory comes from Google Fonts
(https://fonts.google.com) and is distributed under the SIL Open Font License,
Version 1.1 — with the exception noted below. The full licence text is at
https://openfontlicense.org and in each family's page on Google Fonts.

The files were fetched as TrueType instances from the Google Fonts CSS API:

    curl -A "Mozilla/4.0" "https://fonts.googleapis.com/css2?family=<Family>:wght@<weight>"

which serves the unsubsetted `.ttf` for the requested weight. See
`scripts/` history or the commit that introduced this directory for the exact
family/weight table.

Note on naming
--------------

The filename stem is load-bearing: `features/font/fontFaces.ts#parseFontPath`
derives the CSS family name from it, and that name is what
`features/renderer/text.ts` puts into `ctx.font`. Renaming a file here changes
the family of every text element already using it. Add files, don't rename them.

These faces cover Latin only. Korean and other non-Latin text falls back to the
bundled `notosanskr` face, which `renderText` appends to the font stack.
