# Chrome origin-trial tokens for the web build, one per line.
#
# HTML graphics (titles made with the graphic tool, and every example
# template's text) draw through Chrome's html-in-canvas API, which a browser
# only exposes to a page that presents a token for the trial. Register at
# https://developer.chrome.com/origintrials, one token per origin:
#
#   https://cartcut.cartesiancs.com
#   https://<project>.pages.dev, with "match all subdomains" for previews
#
# scripts/buildWeb.mjs writes each token into dist-web/index.html. Tokens are
# public by design, so this file is committed. See scripts/originTrial.mjs.
